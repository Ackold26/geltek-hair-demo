# GELTEK HAIR — лендинг (geltekhair.ru)

Статический лендинг: HTML + CSS + JavaScript, без сборки и внешних зависимостей.
Все ресурсы (шрифты, изображения, логотипы) лежат внутри проекта и подключаются относительными путями — сайт работает на любом хостинге и даже локально из файла.

## Структура

```
geltekhair/
├── index.html            — вся разметка
├── robots.txt            — для поисковых систем
├── sitemap.xml           — карта сайта (домен geltekhair.ru)
├── css/style.css         — стили, адаптив (desktop / планшет / мобильный)
├── js/main.js            — анимации, меню, ссылки магазинов
└── assets/
    ├── fonts/            — Geometria (woff2, 4 начертания)
    └── img/
        ├── bg/ people/ products/ spheres/ icons/ logos/
        └── og.jpg        — превью для соцсетей
```

## Как опубликовать на geltekhair.ru

Сайт — обычная статика, поэтому подходит любой из вариантов:

**A. Классический хостинг / VPS (FTP, cPanel, nginx)**
1. Скопировать всё содержимое папки `geltekhair/` в корень сайта (`public_html`, `www` или корень nginx).
2. Убедиться, что стартовая страница — `index.html` (обычно по умолчанию).
3. Привязать домен `geltekhair.ru` к папке и включить HTTPS (Let's Encrypt).

**B. Netlify / Vercel / GitHub Pages (бесплатно)**
1. Загрузить папку (перетащить в Netlify Drop или запушить в репозиторий).
2. Указать корень публикации — папку с `index.html`.
3. В настройках домена добавить `geltekhair.ru` и настроить DNS по инструкции сервиса.

**C. Проверить локально перед заливкой**
```
cd geltekhair
python -m http.server 8000
```
Открыть http://localhost:8000

> Одностраничный сайт — серверная логика и переадресации не требуются. Достаточно раздачи статики.

## Что можно донастроить (по желанию заказчика)

- **Ссылка «Скачать исследование»** (звёздочка *) сейчас неактивна — задать URL PDF в `js/main.js`, переменная `RESEARCH_URL`.
- **Ссылки магазинов** — заданы в `js/main.js`, объект `SHOP_URLS` (легко заменить на конкретные карточки товара).
- **Ссылка VK** — в `index.html`, атрибут `href` у `.footer__vk`.

## Анимации

- Появление блоков при прокрутке (плавное всплытие).
- Флакон сыворотки спускается по мере прокрутки первого экрана.
- Параллакс фона (производство, фото волос).
- Наведение: подсветка меню, «сжатие» плиток магазинов, увеличение упаковок шампуней.
- Учитывается системная настройка «уменьшить движение» (prefers-reduced-motion).
